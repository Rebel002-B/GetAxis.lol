BETA FEATURE · TOR

Private routing, still being built.

Tor integration is experimental in Axis 0.1.0 and is not fully implemented yet. The goal is to make connection state explicit instead of silently suggesting that a Tor connection exists when it has not actually been verified.

Tor can increase latency and change how websites behave. Axis should only indicate an active Tor state after the connection has been verified. This feature is experimental and may change substantially during Beta.
